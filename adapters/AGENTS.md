## Portable implementation workflow

Use the bundle pinned by `.ai/config.json`; read `.ai/bundles/{version}/docs/DELIVERY.md` for the selection delivery policy. Run doctor once before substantial execution and load only relevant skills/contracts.

Implement the complete requested selection, run affected checks, obtain one independent combined review, fix findings, then publish within existing authorization. Serial work reuses one suitable checkout; concurrent writers claim isolated paths/resources. Tested predecessors can support dependent development before final acceptance. No task or intermediate-group review is required.

Preserve configured quality/security gates, 80% changed coverage, 50 function lines, complexity 10, nesting 3 and actual proof boundaries. Missing tools, empty selections, stale reports and unresolved required findings do not pass. Routine UI proof uses assertions/direct inspection; necessary reader observations remain required. Defer only explicit release-owned matrices/media.

Track one selection in Git-shared state. Commit product changes at natural milestones; check actual product progress every 45 minutes. Optional evidence-tool repair shares two attempts or 20 minutes across the selection, including resumes and renamed phases. Keep the configured required-correction limit. Continue independent work or report exact blockers; never replace failures with invented success.

Report local implementation, actual checks, accepted review and published source separately, including local/PR heads and metadata-only PR edits. “Finish and wrap up” retains the goal; an explicit stop stops work. Honor standing authorization within scope without repeat approval loops. Installation does not resume application tasks.

Preserve task/requirement IDs and unrelated work. Only the coordinator updates task execution fields after selection acceptance. Run the bundled wording checker before delivery. Task observations remain user-level proposals. Read docs/COORDINATION.md and docs/GATES.md only when using their helpers.
