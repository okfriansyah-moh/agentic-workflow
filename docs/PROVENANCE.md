# Source and adaptation record

The 47 reused skills are snapshots of the user's installed local skill directories. Supporting references, scripts, evaluation fixtures, datasets, metadata and existing licenses are retained; dependency caches and filesystem metadata are omitted. Original source tree digests and each installed tree digest are in manifest.json. A digest identifies a local snapshot without pretending it is an upstream release. On 21 October 2026, the repository owner confirmed permission to publish the bundled material in https://github.com/okfriansyah-moh/agentic-workflow. This confirmation supersedes earlier project-owned private-use publication notices for these snapshots; retained third-party licenses, notices and attribution remain applicable. It does not assign a blanket downstream license or replace component-specific terms.

Portable changes replace personal absolute paths with bundle-relative references and user-level storage configuration. The shared wording policy/checker is under resources/wording. Document helper defaults resolve it from their installed file. Task Observer defaults to the user's .codex/skill-workspace and accepts AGENT_WORKFLOW_OBSERVATIONS; it creates no schedules, services or hooks. Existing original global skills are preserved by installation conflict rules.

The reused TDD skill accepts already-approved test boundaries and permits the independent stored-state observation required by ATDD. Code review keeps Standards/Spec evidence but feeds one independent findings ledger rather than requiring nested orchestration or an unavailable issue-tracker setup skill. UI recommendation guidance remains conditional on the adopted design and selected framework. The UI/UX search entrypoint was rewritten to remove a fixed React Native stack, compulsory design generation and automatic persistence; complete supporting search data/scripts remain available. The review entrypoint uses supplied local sources and one existing reviewer without missing tracker-document dependencies. Upstream evidence and negative checker fixtures are retained as evidence, not new output templates.

Seven workflow adaptations derive from the supplied Billing/Officeless skills and latest Forge attachment. They retain task traceability, bounded correction loops, worker reuse, focused self-review, real telemetry and readable evidence. They remove company paths, Ruby/Go-specific rules, fixed models, duplicate approval interviews, tracker/wiki writes, external notifications and predicted quality verdicts. Latest backend and review-verify attachments inform the role catalog; backend now follows selected Kotlin/Node boundaries, and review uses actual checks with the selected 80% changed-line policy.

The contrast arithmetic helper is retained under antislop-human with corrected large-text units and the current sRGB breakpoint. Its retained eight-pair reference table passes the helper self-test.
