Approved scope: resolve four named Claude/Cursor skill conflicts with recoverable directory backups; repair 47 matching reused-skill records; add native-host verification records; install Playwright CLI, hosted Context7 MCP and isolated Strix; add three managed skills for a total of 74. Keep eight roles, inherited models, project pins and one Forge loop. Do not execute movie-app tasks or change its original documents.

Writing lanes use recorded Git bases and claims. Installer owner edits installer.py and conflict-resolution helpers/tests. Tools owner edits tools modules, tools registry/lock, tool tests and three new skill directories plus the two existing video/evidence skills. Native verification owner edits host verification modules/tests and host documentation. Parent owns CLI registration, version/manifest/catalog/schema changes, browser fixtures, release documentation and final integration/installation. Avoid concurrent edits to another owner's files; communicate interface changes.

Every runtime module exposes register(subparsers). The parent imports tools and host_verification in cli.py; modules must not register themselves elsewhere. CLI handlers return JSON dictionaries, with failed/blocked/error mapped to nonzero by the parent CLI. Use standard-library orchestration; optional downloaded tools are external dependencies. Root paths derive from __file__; local installation source must remain relocatable. Tool state is outside committed bundles. Host verification proof is distinct from structural inspection and missing trust/auth never passes. No bypass flags, model overrides, autonomous Strix scans, or secret values in retained logs.

1.1.0 is assembled and tested here before explicit installation into the source checkout, global homes and movie-app. Parent refreshes skill checksums after all skill edits. Workers commit their bounded changes, capture real checks against that commit and return claim/receipt paths for independent review. Git union merging is not used.
