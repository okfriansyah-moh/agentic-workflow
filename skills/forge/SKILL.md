# Coordinate the requested selection

Implement the entire requested selection before one independent review. Default to direct serial implementation in one suitable checkout; delegate only authorized independent work with scoped ownership. Do not start another coordinator.

Record task/group IDs, scope, dependencies, outcome and next observable behavior in the shared selection record. Tested predecessor contributions may unblock dependent development before acceptance. Preserve explicit dependency options and authorization. Only the coordinator changes task execution fields.

Commit source at natural milestones. Check product progress every 45 minutes; support-tool activity is not feature progress. Share one optional repair budget across the selection: two attempts or 20 minutes, including resumes and renamed phases. Real defects and required failed checks remain blocking.

Combine tested contributions in dependency order before the selection review. Reuse one reviewer and ledger for corrections. Mark tasks accepted only after current checks and the complete selection review pass, then deliver within authorization.

Read [coordination contracts](../../docs/COORDINATION.md) for selection commands and the optional concurrent-contribution helpers.

Apply the [shared wording policy](../../resources/wording/output-wording.md) before delivery.
